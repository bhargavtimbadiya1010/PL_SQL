# 🚀 PL/SQL Programs

Welcome to my **PL/SQL Programs** repository! 💻

This repository contains a collection of **Oracle PL/SQL programs** created for learning and practicing database programming.

The programs in this repository cover concepts ranging from **basic to advanced PL/SQL**, making it useful for students, beginners, and anyone interested in improving their database programming skills. 📚

---

## 📌 About

**PL/SQL (Procedural Language/SQL)** is Oracle's procedural extension to SQL.

It combines the power of SQL with programming features that help developers create efficient and structured database applications.

This repository is created to provide practical experience with PL/SQL through simple and easy-to-understand programs. 💡

---

## 🛠️ Requirements

To run the programs in this repository, you can use:

- 🏢 Oracle Database
- 💻 Oracle SQL Developer
- 🌐 Oracle Live SQL

---

## ▶️ How to Run

1. 💻 Open an Oracle-compatible SQL environment.
2. 📂 Open the required `.sql` file.
3. 🖨️ Enable `DBMS_OUTPUT` if required.
4. ▶️ Execute the PL/SQL code.
5. 📊 View the output.
